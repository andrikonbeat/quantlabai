# Security Policy

## Supported Versions

QuantLab AI is under active development. Security updates are provided for the
latest state of the `main` branch. Older releases and feature branches are not
supported unless otherwise stated.

| Version | Supported |
|---------|-----------|
| latest (`main`) | Yes |
| previous releases | No |

## Reporting a Vulnerability

Please report security vulnerabilities privately via GitHub's
[Private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
for this repository — do **not** open a public issue or PR for a
vulnerability.

### What to include

- Affected version(s) / commit(s)
- Steps to reproduce (minimal, if possible)
- Impact description
- Suggested fix (optional)

### Response expectations

- First response / acknowledgement: within **7 days**
- Triage and fix released: within **30 days**, depending on severity and
  complexity
- Disclosure: coordinated with the reporter

## Scope

- **In scope**: the QuantLab AI SDK code, CLI, infrastructure definitions, and
  supporting tooling in this repository.
- **Out of scope**: trading advice, strategy performance, or financial
  decisions made using the software. QuantLab AI is a research tool, not
  financial advice.
