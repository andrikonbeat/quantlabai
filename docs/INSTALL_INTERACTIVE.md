# QuantLab AI - Instalador interactivo

Copia y pega este comando en tu terminal:

```bash
curl -fsSL https://raw.githubusercontent.com/ogzuz/quantlab/main/install.sh | bash
```

O, si ya tienes el repo clonado:

```bash
./install.sh
```

El instalador detecta tu SO, explica QuantLab y dependencias, guía instalación de OpenCode/SQX/JForex, verifica componentes y te deja listo para abrir OpenCode con el agente `quantlab-orchestrator`.
